Edge & Fog Computing

Intelligence at the Gateway

Not every IoT decision needs a round-trip to the cloud. Nebulae deploys edge computing applications on IoT gateways — local anomaly detection, protocol translation, data aggregation, and ML inference — so your system responds in milliseconds and keeps working without internet.

80%BW Reduction
<100msResponse

OTAManaged
  • Local Data Aggregation — Aggregate and compress 1000s of sensor readings per minute before cloud push
  • Protocol Translation — Modbus RTU → MQTT, RS-485 → REST, OPC-UA → InfluxDB — at the edge
  • Edge Inference — TensorFlow Lite / ONNX Runtime models for anomaly detection and predictive maintenance
  • Local Rules Engine — Threshold alerts and relay control with sub-100ms response — no cloud dependency
  • Offline Buffering — Local SQLite / InfluxDB buffer — sync to cloud on reconnect, no data loss
  • OTA-Managed Edge Apps — Docker container or swupdate-based OTA — push edge app updates remotely
Edge Architecture

3-Tier IoT Edge Architecture

TierLocationFunction
Device / NodeField sensorData acquisition, low-power TX
Edge / Fog NodeSite gatewayAggregation, inference, local rules
CloudData centre / AWSLong-term storage, ML training, BI

The edge tier reduces cloud bandwidth by filtering and aggregating: a factory with 200 sensors sending 10 readings/second generates 2,000 msg/sec. Edge aggregation can reduce this to 20 summarised msg/min — a 6,000× bandwidth reduction.
