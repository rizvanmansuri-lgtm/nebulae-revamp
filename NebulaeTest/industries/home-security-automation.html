Wireless door/window/motion sensors with instant push alert and siren trigger.

Smart Access Control

Energy Management

Wi-Fi cameras with motion zone detection, cloud archive, and event timeline.

Mobile App Control

Flutter-based app — arm/disarm, scene control, live camera, energy dashboard.

System Architecture

From Sensor to App

  • Zigbee Mesh Layer — Sensors and actuators form a self-healing mesh — up to 65K devices per network
  • Home Gateway / Hub — Nebulae Zigbee gateway bridges mesh to Wi-Fi; runs local rule engine offline
  • Cloud Backend — MQTT/REST — event push, remote access, scene sync, and OTA update
  • Mobile App — Flutter iOS/Android — live status, arm/disarm, camera feed, energy charts
  • Voice Assistant — Alexa, Google Home, and Apple HomeKit / Matter integration
