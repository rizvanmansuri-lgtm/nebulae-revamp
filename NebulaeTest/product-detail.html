About NLC1110

The NLC1110 is Nebulae's industrial controller for smart city infrastructure and industrial automation. DIN rail mountable for installation in electrical panels, it connects field devices to the NebuLink cloud via cellular backhaul — providing remote monitoring and control of actuators, valves, and loads.

Multi-protocol RF support enables the NLC1110 to communicate with diverse field devices using 6LoWPAN, Zigbee, or LoRa — while the cellular uplink provides cloud connectivity without requiring fixed network infrastructure at the installation site.

MQTT and HTTP protocol support ensures compatibility with any cloud IoT platform — NebuLink Middleware, AWS IoT, Azure IoT Hub, or custom on-premise systems. Remote OTA firmware updates minimise maintenance visits to remote installation sites.
